| 項目         | 内容                                                |
| ---------- | ------------------------------------------------- |
| **定義**     | 貴腐菌（Botrytis cinerea）がぶどうに感染し、水分が蒸発して糖度が極端に高くなる現象 |
| **ぶどうの変化** | 粒がしぼみ、糖・酸・香り成分が**凝縮**される                          |
| **結果**     | 非常に濃厚で甘く、複雑な香りを持つワインができる                          |
| **自然条件**   | 朝霧と昼の晴天を繰り返す気候（湿度と乾燥のバランス）が必要                     |
| **英語**     | Noble Rot（高貴な腐敗）                                  |

---

## 🍷 貴腐ワインの特徴

| 特徴       | 内容                                         |
| -------- | ------------------------------------------ |
| 香り       | ハチミツ、アプリコット、トロピカルフルーツ、サフラン、ドライフルーツなどの濃厚な香り |
| 味わい      | 非常に甘く、酸とのバランスが良いものが多い                      |
| 色合い      | 黄金色〜琥珀色                                    |
| 熟成ポテンシャル | 非常に高い。数十年単位で熟成可能                           |
| 価格帯      | 高価（収穫が手作業で不安定なため）                          |

|国|地域・ワイン名|

|ドイツ|ベーレンアウスレーゼ（BA）、トロッケンベーレンアウスレーゼ（TBA）など|
|ハンガリー|トカイ（Tokaji） → トカイ・アスーが有名|
|オーストリア|ヴァッハウなどで貴腐ワインが生産されている|

---

## ☠️ 貴腐 vs 灰色かび（悪性の腐敗）

|種類|内容|
|---|---|
|**貴腐菌（善玉）**|水分を蒸発させ、糖度を高める。ワイン用に理想的な菌|
|**灰色かび病（悪玉）**|同じ菌だが、湿度が高すぎると腐敗してぶどうが腐る（病気になる）|

---

## 📝 まとめ

> **「貴腐」とは、貴腐菌による奇跡的な自然現象**  
> → その結果できる「貴腐ワイン」は、**甘口ワインの最高峰**とされます。
