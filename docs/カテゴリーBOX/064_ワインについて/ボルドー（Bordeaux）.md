「ボルドー（Bordeaux）」は、世界的に有名な**フランス最大級のワイン産地**であり、「赤ワインの代名詞」とも言える存在です。ただし、白や甘口、ロゼ、スパークリングも造られています。

---

## 🍷 ボルドーワインとは？

> フランス南西部「ボルドー地方」で生産されるワインの総称。  
> 川や気候、土壌の違いからさまざまなワインスタイルが生まれている。

---

### 🗺 地理的特徴

- **ジロンド川を中心**に、左右で性格が異なる：

| エリア                   | 特徴                    |
| --------------------- | --------------------- |
| **左岸（メドックなど）**        | 力強く、長期熟成型の赤ワインが多い。    |
| **右岸（サンテミリオン、ポムロール）** | 柔らかく、親しみやすい味の赤ワインが多い。 |
| **アントル・ドゥ・メール**       | 爽やかで軽快な白ワインが多いエリア。    |
    
---

### 🍇 主な使用ブドウ品種

|種類|品種|特徴|
|---|---|---|
|**赤ワイン**|メルロー、カベルネ・ソーヴィニヨン、カベルネ・フラン|果実味と渋みのバランスが良く、複雑で奥行きのある味わいに。|
|**白ワイン**|ソーヴィニヨン・ブラン、セミヨン、ミュスカデル|爽やかで香り高いものや、貴腐ワインなど甘口もある。|

### 🍽 ボルドーワインの味わいとペアリング

|ワインタイプ|味の特徴|合う料理|
|---|---|---|
|**左岸の赤（カベルネ主体）**|渋みがあり重厚、長期熟成に向く|牛ステーキ、熟成チーズ|
|**右岸の赤（メルロー主体）**|柔らかく果実味が豊か|ローストポーク、ミートパイ|
|**白（辛口）**|爽やかでハーブ香|サラダ、魚介料理|
|**白（甘口）**|ハチミツやアプリコットの香り|フォアグラ、ブルーチーズ、デザート|

---

### ✅ ボルドーの魅力まとめ

- 世界中のワイン文化に影響を与えた「赤ワインの中心地」
    
- ブレンドによる複雑な味わい
    
- 熟成ポテンシャルが高い（ヴィンテージによって変化する楽しさ）
    
- 高級シャトーから手頃なボトルまで価格帯が広い
