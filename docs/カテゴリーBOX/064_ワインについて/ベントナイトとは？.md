> **主成分：モンモリロナイト（Montmorillonite）**  
> 火山灰が長い年月をかけて変質してできた**非常に細かい粒子の粘土**。

- 高い吸着性と膨潤性（水を含むと膨らむ性質）が特徴
    
- 無味無臭・無害で、食品添加物としても安全に使用可能
    

---

## 🍷 ワインづくりでのベントナイトの役割

### 🎯 主目的：**清澄（清澄化）**

- 発酵後のワインには、**酵母の死骸、タンパク質、ポリフェノール、微生物の残骸**などの微細な不純物が含まれる
    
- ベントナイトを加えると、**これらが吸着され、沈殿してワインが透明になる**
    

---

### 🧪 特に重要な働き：**タンパク質の除去**

- 白ワインでは**タンパク質の残留が濁りや沈殿の原因**になる
    
- ベントナイトは、これらのタンパク質を選択的に吸着・沈殿させる
    
- これにより、**瓶詰後にワインが曇るのを防止**できる
    

---

## 🧫 使用方法（簡易フロー）

1. 水に溶かしてベントナイトを膨潤させる
    
2. ワインに添加
    
3. 数日〜1週間置くと、不純物と共に沈殿
    
4. 上澄みを取り出し、澱（おり）を除去
    

---

## 🧾 ベントナイトと他の清澄剤の違い

|清澄剤|主成分|特徴|
|---|---|---|
|**ベントナイト**|粘土（鉱物性）|タンパク質除去に強力。白ワインに多用。|
|**ゼラチン**|動物性タンパク質|赤ワインの苦味や渋みをまろやかに。|
|**卵白**|卵の白身タンパク|赤ワインの澄まし用。高級ボルドーで伝統的。|
|**活性炭**|炭素|臭いや色素の除去に使用。|

## ✅ まとめ：ベントナイトとは

| 観点         | 内容                            |
| ---------- | ----------------------------- |
| **何か？**    | 火山由来の粘土鉱物。吸着性が非常に高い。          |
| **なぜ使う？**  | ワインの不純物（特にタンパク質）を除去し、清澄にするため。 |
| **どこに使う？** | 主に白ワインやスパークリングワインで使用される。      |
| **利点**     | 無味無臭で、風味を変えずに安定したワインを得られる。    |
