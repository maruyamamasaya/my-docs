### 🍷 主な情報（表ラベル／フロントラベル）

| 項目                | 説明                                           |
| ----------------- | -------------------------------------------- |
| **ワイン名**          | 生産者独自のブランド名、ブドウ畑の名前、またはキュヴェ名など。              |
| **生産者名（または醸造所名）** | ワインを製造・瓶詰した会社や個人の名前。                         |
| **ヴィンテージ（収穫年）**   | 使用されたブドウが収穫された年。ブドウの出来を判断する目安に。              |
| **原産地（産地名）**      | 国・地域・村名・畑名など。例：Bordeaux（フランス・ボルドー）           |
| **格付け**           | AOC, DOCG, VDPなど。産地による品質保証制度（後述）。            |
| **ブドウ品種**         | 使用されたブドウの種類（記載がない場合も多い）。例：Cabernet Sauvignon |
| **アルコール度数**       | 通常は12〜15%程度。                                 |
| **容量**            | 一般的には750ml。                                  |

---

### 🍇 裏ラベル（バックラベル）によくある情報

|項目|説明|
|---|---|
|**味わいの説明**|「フルーティでまろやか」「タンニンがしっかり」などのテイスティングコメント。|
|**飲み頃温度・ペアリング**|「16〜18℃で提供」「赤身肉に合う」などの推奨情報。|
|**輸入業者名**（日本向け）|海外ワインの場合、輸入業者の情報が日本語で記載されている。|
|**バーコードや法的表記**|アルコール飲料としての義務情報。|

---

### 🏷 格付けや認証マーク（例）

|国|表示例|意味|
|---|---|---|
|フランス|AOC / AOP|原産地呼称統制ワイン（厳しい基準）|
|イタリア|DOC / DOCG|高品質ワインの証（DはDenominazione）|
|ドイツ|QbA / Prädikatswein|等級によって糖度や熟成度が異なる|
|スペイン|DO / DOCa|地域ごとの格付け制度|

---

### 📌 注意点

- **新世界のワイン（チリ、オーストラリアなど）**はブドウ品種や味の説明が明確に書かれていることが多いです。
    
- **旧世界のワイン（フランス、イタリアなど）**は土地の名前や格付けだけで、品種が明記されていないこともあります。
