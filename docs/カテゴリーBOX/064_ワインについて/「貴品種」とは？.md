> **高品質なワインを生むことができる、世界的に評価の高いぶどう品種のこと。**

以下のような特徴を持ちます：

| 特徴             | 内容                               |
| -------------- | -------------------------------- |
| 🌍 世界的に評価されている | フランス・イタリア・ドイツ・アメリカなどで使用されている国際品種 |
| 🍷 品質の高いワインになる | 熟成ポテンシャル・複雑な香り・繊細な味わいを持つ         |
| 🧪 テロワールに敏感    | 土壌・気候・作り手の影響がワインの個性に反映されやすい      |
| 🏅 高級ワインに使われる  | 有名な格付けワインや高額ワインに用いられることが多い       |

---

## 🍷 主な「貴品種」の例（赤・白）

### 🔴 赤ワイン用

| 品種名              | 特徴・代表産地                    |
| ---------------- | -------------------------- |
| **カベルネ・ソーヴィニヨン** | 力強い渋みと熟成能力。ボルドーやナパに多い      |
| **ピノ・ノワール**      | 繊細でエレガント。ブルゴーニュが代表格        |
| **メルロー**         | 柔らかく果実味が豊か。カベルネとブレンドされることも |
| **シラー／シラーズ**     | スパイシーで濃厚。ローヌ地方やオーストラリアに多い  |
| **ネッビオーロ**       | バローロなどに使われるイタリアの高貴品種       |

### ⚪ 白ワイン用

|品種名|特徴・代表産地|
|---|---|
|**シャルドネ**|熟成や樽との相性もよく、非常に多彩なスタイルで造られる|
|**リースリング**|甘口〜辛口まで幅広い。ドイツが代表的|
|**ソーヴィニヨン・ブラン**|ハーブ香や爽やかな酸味。ロワールやニュージーランドで人気|
|**セミヨン**|貴腐ワイン（ソーテルヌ）にも使われる品種|
|**ヴィオニエ**|華やかな香り。ローヌ地方などで使われる|

---

## 🔍「貴品種」と「土着品種（ローカル品種）」の違い

|分類|説明|例|
|---|---|---|
|**貴品種**|高評価で広く使われる高級ワイン用品種|カベルネ・ソーヴィニヨン、シャルドネなど|
|**土着品種**|特定地域にしかない伝統的・地元限定の品種|テンプラニーリョ（スペイン）、グリューナー・ヴェルトリーナー（オーストリア）など|

---

## 📝 まとめ

> 「貴品種」とは、**ワイン品質の高さで“貴ばれている”ぶどう品種**。  
> 世界中の高級ワインで使われ、繊細で複雑なワインを生み出す。
