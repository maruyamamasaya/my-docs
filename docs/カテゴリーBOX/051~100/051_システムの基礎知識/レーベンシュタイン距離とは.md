**レーベンシュタイン距離**（Levenshtein distance）は、  
**2つの文字列の違いを測る指標**のことだよ。

具体的には、  
「ある文字列を別の文字列に変換するために必要な**最小の編集回数**」を表すんだ。  
ここでいう「編集」とは次の3種類：

- **挿入**（insert）…文字を1つ追加する
    
- **削除**（delete）…文字を1つ消す
    
- **置換**（substitute）…文字を1つ別の文字に変える
    

たとえば：

|文字列A|文字列B|レーベンシュタイン距離|編集内容例|
|---|---|---|---|
|"kitten"|"sitting"|3|k→s（置換）、e→i（置換）、末尾にgを挿入|

---

### どういう経緯で作られた？

この概念を考案したのは、  
ソ連の科学者「**ウラジーミル・レーベンシュタイン**」だよ（1965年）。

**背景と経緯**はざっくりこう：

- 当時、情報理論（情報を効率よく正確に伝える技術）の研究が盛んだった
    
- 通信中に**ノイズ**が発生して文字や信号が変わってしまう問題が大きかった
    
- つまり、**「どれくらい変わったか」を測る指標が必要**だった
    
- そこで、レーベンシュタインが「編集回数で差を測ろう」と提案した
    

つまり、  
**もともとは文字列の誤り検出や修正（エラー訂正符号）のために生まれた関数**なんだ！

---

# レーベンシュタイン距離の超シンプルな考え方

2つの文字列があったとする。

たとえば

- A = "kitten"
    
- B = "sitting"
    

これを、「小さなステップ」でどんどん変えていくと考える。

基本ルールはたったこれだけ：

|編集操作|何をする？|コスト（重さ）|
|---|---|---|
|削除|Aの1文字を消す|+1|
|挿入|Bの1文字を足す|+1|
|置換|Aの1文字をBの文字に変える|+1|
|何もしない|AとBの文字が同じなら何もしない|+0|

---

# アルゴリズムざっくり手順（日本語で）

1. **表（2次元のマス目）を作る**  
    　縦にA（"kitten"）、横にB（"sitting"）を並べる。
    
2. **最初の行と列を初期化する**  
    　文字がないところから文字を作るには「全部挿入」だから、  
    　たとえば最初の列は「0,1,2,3,4,5,6」と順番に。
    
3. **1文字ずつ比べながら、最小のコストを選ぶ**  
    　今いるマスは、次の3つの選択肢から「いちばん安い道」を選ぶ。
    

　- 左のマス（挿入）＋1

- 上のマス（削除）＋1
    
- 左上のマス（置換 or 何もしない）＋（同じなら0、違ったら1）
    

4. **全部のマスを埋めていく**
    
5. **最後のマスに書かれている数字が、レーベンシュタイン距離！**
    

---

# もう少しイメージでいうと

「道を歩く」ゲームに近いんだ。

- 挿入する：右に一歩
    
- 削除する：下に一歩
    
- 置換する／何もしない：斜めに一歩
    

で、**なるべくコストが安い道**を選びながらゴールを目指す！

# ポイントまとめ

- 文字列AとBを縦横に並べる
    
- 小さな操作（挿入・削除・置換）を考える
    
- コストが少ない道を選んでいく
    
- 最後にできたコストが「レーベンシュタイン距離」

# Pythonで書くレーベンシュタイン距離

```
def levenshtein_distance(a, b):
    # 文字列aとbの長さを取得
    len_a = len(a)
    len_b = len(b)

    # 空の表（2次元リスト）を作る
    dp = [[0] * (len_b + 1) for _ in range(len_a + 1)]

    # 最初の行と列を初期化
    for i in range(len_a + 1):
        dp[i][0] = i
    for j in range(len_b + 1):
        dp[0][j] = j

    # 表を埋めていく
    for i in range(1, len_a + 1):
        for j in range(1, len_b + 1):
            if a[i-1] == b[j-1]:
                cost = 0  # 同じ文字ならコスト0
            else:
                cost = 1  # 違う文字なら置換コスト1

            dp[i][j] = min(
                dp[i-1][j] + 1,    # 削除
                dp[i][j-1] + 1,    # 挿入
                dp[i-1][j-1] + cost  # 置換
            )

    # 最後のマスがレーベンシュタイン距離
    return dp[len_a][len_b]

# 使ってみる
a = "kitten"
b = "sitting"
print(f"{a} と {b} のレーベンシュタイン距離は {levenshtein_distance(a, b)} です")
```

実行すると
```
kitten と sitting のレーベンシュタイン距離は 3 です
```

と出るよ！

---

# 超簡単にまとめると

- `dp[i][j]`は、「aの最初のi文字」と「bの最初のj文字」の最小編集距離
    
- どの操作が一番楽（コスト小さい）かを選びながら進む
    
- 最後の`dp[len(a)][len(b)]`が答え！

# 改良版：ヘッダーつきレーベンシュタイン距離可視化コード

```
def levenshtein_distance_visualize(a, b):
    len_a = len(a)
    len_b = len(b)

    # 表を作る（dp[i][j]はaのi文字目とbのj文字目までの距離）
    dp = [[0] * (len_b + 1) for _ in range(len_a + 1)]

    # 初期化
    for i in range(len_a + 1):
        dp[i][0] = i
    for j in range(len_b + 1):
        dp[0][j] = j

    # ヘッダー表示用に関数を定義
    def print_table(dp, a, b):
        # 横ヘッダー
        print("    ", end="")
        for ch in " " + b:  # 最初は空文字にする
            print(f"{ch:>3}", end="")
        print()
        # 表の中身
        for i, row in enumerate(dp):
            if i == 0:
                label = " "
            else:
                label = a[i-1]
            print(f"{label:>3}", end="")
            for cell in row:
                print(f"{cell:>3}", end="")
            print()
        print()

    # 最初の表（初期化だけ終わった状態）
    print("---- 初期状態 ----")
    print_table(dp, a, b)

    # 更新しながら表を都度表示
    for i in range(1, len_a + 1):
        for j in range(1, len_b + 1):
            if a[i-1] == b[j-1]:
                cost = 0
            else:
                cost = 1

            dp[i][j] = min(
                dp[i-1][j] + 1,    # 削除
                dp[i][j-1] + 1,    # 挿入
                dp[i-1][j-1] + cost  # 置換
            )

            # 更新後の表を表示
            print(f"---- i={i}({a[i-1]}), j={j}({b[j-1]}) ----")
            print_table(dp, a, b)

    return dp[len_a][len_b]

# 実行してみる
a = "kitten"
b = "sitting"
print(f"{a} と {b} のレーベンシュタイン距離は {levenshtein_distance_visualize(a, b)} です")

```
