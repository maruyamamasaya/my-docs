# 📖 もう少し詳しく

- Amazon自身がAIモデルを作ったわけではない
    
- いろんなAI企業（Anthropic、Cohere、Stability AI、Meta、Mistral、AI21 Labsなど）の  
    **人気の高性能AI（LLMとか画像生成AI）**を、  
    **まとめて使える場所**をAWS上に用意した！
    
- 自分でGPUを用意したり、モデルを訓練したりしなくていい
    
- API経由で「テキスト生成」「要約」「画像生成」などができる
    
- しかも、自社のデータを安全に使ってカスタマイズ（チューニング）もできる
    

つまり、  
**AIをフル活用したいけど、自前でモデルを訓練したり、管理したくない企業向け**だね。

---

# 🏢 どんな企業に向いてる？

- 自社アプリにチャットAIを組み込みたい
    
- 社内文書検索をAIでやりたい
    
- 自社専用のQ&Aボットを作りたい
    
- でも、自前でAIモデルを育てるリソースはない…
    

そんなとき、**Bedrockを使えば即戦力**になる。

---

# ✨ Bedrockの特徴まとめ

|特徴|内容|
|---|---|
|モデルが選べる|複数ベンダーの最新AIモデル（Claude、Titan、Stable Diffusionなど）を好きに使える|
|フルマネージド|AWSが全部裏側を管理してくれる（サーバー管理・拡張・更新も不要）|
|セキュリティ万全|AWS基準のセキュリティで、自社データを守れる|
|カスタマイズ可能|自社データを使ってモデルを少しだけ学習させる（ファインチューニングやRAGができる）|
|APIで簡単操作|コード数行でAIにアクセスできる|
