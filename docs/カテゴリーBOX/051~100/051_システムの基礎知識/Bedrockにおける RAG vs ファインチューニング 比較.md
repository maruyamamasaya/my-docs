|項目|RAG（検索拡張生成）|ファインチューニング（微調整学習）|
|---|---|---|
|ざっくり流れ|質問に対して「外部データを引っ張ってきてAIに渡す」|自社データを使って「モデル自体を再学習させる」|
|使うサービス|📚 Knowledge Bases for Amazon Bedrock（＋ベクトルDB）|🛠️ Model customization（カスタマイズ機能）|
|必要なもの|- 参照用ドキュメント（PDF, TXT, HTMLなど）  <br>- ベクトルDB（OpenSearch Serverlessなど）|- ファインチューニング用のデータセット（質問と回答のペア、分類データなど）|
|具体的な作業|1. S3にドキュメントアップロード  <br>2. Knowledge Baseを作成  <br>3. 質問したら自動で検索→生成|1. トレーニングデータを準備  <br>2. Bedrockコンソールから「カスタマイズジョブ」を開始  <br>3. 数時間〜数日待つ|
|時間感覚|セットアップすれば即使える（数時間）|学習に数時間〜数日かかる|
|柔軟性|ドキュメント更新すれば即反映|モデルを再学習しないと反映されない|
|コスト感|安い（API使用料＋ベクトルDB代くらい）|高い（カスタマイズ料金＋学習コスト）|
|代表的なモデル|Claude 3 + Titan Embeddings など|Titan Text + カスタマイズ版|
