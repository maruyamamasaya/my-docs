# 🗺 地域別・スパークリングワインのジャンルまとめ

| 地域                           | 名称                         | 主な品種・製法                       | 特徴                            |
| ---------------------------- | -------------------------- | ----------------------------- | ----------------------------- |
| 🇫🇷 **フランス・シャンパーニュ地方**      | **シャンパーニュ**                | シャルドネ、ピノ・ノワール、ピノ・ムニエ / 瓶内二次発酵 | 世界最高峰の泡、複雑で上質、熟成香・細かい泡        |
| 🇫🇷 **フランス各地（アルザス、ロワールなど）** | **クレマン（Crémant）**          | 地域品種使用 / 瓶内二次発酵               | 上品でコスパ良。シャンパーニュに似たスタイル        |
| 🇫🇷 **ラングドック地方**            | **ブランケット・ド・リムー**           | モーザックなど / 瓶内発酵                | 世界最古の発泡製法。やや素朴で自然派も多い         |
| 🇪🇸 **スペイン・カタルーニャ地方**       | **カヴァ（Cava）**              | マカベオ、チャレッロ、パレリャーダ / 瓶内二次発酵    | クリスプで爽やか。コスパ最強。Brut Natureも豊富 |
| 🇮🇹 **イタリア・ヴェネト州**          | **プロセッコ（Prosecco）**        | グレーラ種 / シャルマ（タンク）方式           | フルーティ＆軽快。アペリティフに最適            |
| 🇮🇹 **イタリア・ロンバルディア州**       | **フランチャコルタ（Franciacorta）** | シャルドネ、ピノ・ネーロ / 瓶内二次発酵         | シャンパーニュに近い高品質イタリア泡。熟成感あり      |
| 🇩🇪 **ドイツ**                 | **ゼクト（Sekt）**              | リースリングなど / 瓶内 or タンク          | 品質差大きい。リースリング使用のものは爽やかで華やか    |
| 🇺🇸 **アメリカ（カリフォルニアなど）**     | **スパークリング・ワイン**            | シャルドネ、ピノ・ノワール等 / 瓶内 or タンク    | フルボディで果実味あり。シャンパンメゾン直系も多数     |
| 🇯🇵 **日本（山梨、長野など）**         | **日本産スパークリング**             | 甲州、マスカット・ベーリーA等 / 各種製法        | 繊細でやさしい泡。和食とも調和する味わい          |

## 🧭 ジャンル別・選び方のヒント

|飲みたいスタイル|おすすめ|
|---|---|
|祝い事・贈答・特別な日|シャンパーニュ、フランチャコルタ|
|コスパ重視・毎日の乾杯|カヴァ、クレマン、プロセッコ|
|軽くてフルーティ|プロセッコ、ゼクト（リースリング）|
|熟成感・ナッツ香など深み|シャンパーニュ、フランチャコルタ、クレマン・ド・ブルゴーニュ|
|和食に合う泡|日本ワイン、ピノ・ノワール系クレマン|

## ✨補足

- **瓶内二次発酵**：細かい泡、熟成に向く（シャンパーニュ、クレマンなど）
    
- **シャルマ方式（タンク方式）**：軽快でフルーティ（プロセッコなど）
    
- 地名がワイン名になるケースが多い（Champagne, Cava, Prosecco など）
