| 特徴                | 説明                                          |
| ----------------- | ------------------------------------------- |
| 🍑 **果実味が強い**     | 桃・洋梨・パイナップルなどの熟した果物感が前面に出る                  |
| 🌿 **酸が穏やか**      | ヨーロッパ産より柔らかく、甘味とのバランスでまろやかに                 |
| 🍯 **ドサージュ多めもあり** | Extra Dry（やや甘）タイプも流通。Brutでも「甘く感じる」場合も       |
| ☀️ **気候の影響**      | 日照量が多く、糖度の高いブドウが育ちやすい（＝アルコール高め＆甘く感じやすい）     |
| 🏷 **品種の自由度が高い**  | シャルドネ、ピノ・ノワールの他、モスカート（マスカット）などアロマティック品種も使用可 |

## 🥂 よく見かけるタイプ

|ラベル表記|実際の味わい傾向|
|---|---|
|**Brut**（辛口）|果実味の甘やかさがあるため、ヨーロッパのBrutより“ほんのり甘く”感じることも|
|**Extra Dry**|実はBrutより“甘め”です（名前に惑わされないよう注意）|
|**Moscato d’Asti風（マスカット系）**|はっきり甘口。デザートワイン的|

## 🏆 有名なカリフォルニアのスパークリング・ブランド

|ブランド|特徴|
|---|---|
|**Schramsberg（シュラムスバーグ）**|歴代大統領も愛飲。瓶内二次発酵で本格派|
|**Roederer Estate（ロデレール・エステート）**|仏シャンパンのロデレール社直系。繊細で高品質|
|**Mumm Napa（マム・ナパ）**|フランスのマム社の姉妹ブランド。華やか＆親しみやすい|
|**Chandon California（シャンドン・カリフォルニア）**|モエ・エ・シャンドンが展開。果実味が豊かで飲みやすい|

## 🎯 結論

- ✅「飲みやすくてちょっと華やか」な泡が好きなら、アメリカ産はとてもおすすめ
    
- ❗「キリッと辛口」「骨太な酸とミネラル」が好きなら、フランス（シャンパーニュやクレマン）の方が合うかも
