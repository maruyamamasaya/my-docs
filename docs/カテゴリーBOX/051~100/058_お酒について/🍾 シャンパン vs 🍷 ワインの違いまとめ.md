| 項目    | シャンパン（Champagne）         | ワイン（Wine）           |
| ----- | ------------------------ | ------------------- |
| 発泡    | あり（スパークリングワインの一種）        | なし（多くは非発泡）          |
| 産地    | フランス・シャンパーニュ地方限定         | 世界各地（仏・伊・米・チリ・日本など） |
| 製法    | **瓶内二次発酵（シャンパーニュ方式）**    | 基本は一次発酵のみ           |
| 気圧    | 5〜6気圧（高圧）                | 非発泡または低圧の微発泡もあり     |
| 味の特徴  | 繊細な泡、酸味、ブリオッシュ香など        | ブドウ品種・地域によって大きく変化   |
| 使用品種  | シャルドネ、ピノ・ノワール、ムニエ（3種）    | 地域・ワインごとに多種多様       |
| 熟成    | 最低15ヶ月（ノンヴィンテージ）、長期熟成もあり | 短期〜長期熟成まで幅広い        |
| 法的保護  | 原産地名称保護制度（AOC）で厳格に定義     | AOC、DOCなど各国の制度に準ずる  |
| 価格帯   | 高め（製法とブランド性）             | 広範囲（安価〜超高級）         |
| 使用シーン | 結婚式・祝宴・乾杯などに定番           | 食中・日常飲用・贈答など幅広い     |

## 🍾 シャンパンの特徴

### 🔹 定義

「シャンパン」と名乗るには以下のすべてが必要です：

1. **フランス・シャンパーニュ地方で生産されたもの**
    
2. **シャンパーニュ方式（瓶内二次発酵）で造られている**
    
3. **指定された3品種（シャルドネ、ピノ・ノワール、ムニエ）を使用**
    
4. **AOC（原産地統制呼称）に適合**
    

> 他地域で同じ製法でも「シャンパン」は名乗れず、「スパークリングワイン」「カヴァ」「スプマンテ」などと呼ばれます。

### 🔹 風味

- 繊細できめ細かい泡
    
- 焼きたてパンやナッツのような香ばしさ（酵母熟成による）
    
- しっかりした酸味とミネラル感
    

---

## 🍷 ワインの特徴（非発泡が基本）

### 🔹 概要

- 発酵によってブドウ果汁から生まれる醸造酒
    
- 赤・白・ロゼに分かれ、発泡しないものが大多数
    

### 🔹 風味と多様性

- ブドウ品種・テロワール（土壌・気候）・醸造法によって個性が激変
    
- 赤：渋みと果実味
    
- 白：酸味や果実の軽やかさ
    
- ロゼ：赤白の中間、香り高く軽やか
    

---

## 💡 補足：スパークリングワインとシャンパンの関係

|種類|国・特徴|
|---|---|
|**シャンパン**|フランス・シャンパーニュ地方、瓶内二次発酵|
|カヴァ|スペインのスパークリング。シャンパンと同じ製法|
|スプマンテ|イタリアの泡ワイン。甘口も多い|
|セクト|ドイツのスパークリングワイン|
|クレマン|フランスの他地域で作られる瓶内発酵ワイン|

---

## 🎯 まとめ：両者の最大の違いは？

|本質的な違い|説明|
|---|---|
|「どこでどう造られたか」|シャンパンは地域・製法・品種すべてが厳格に定義される|
|「泡の有無」|シャンパンは泡が命。ワインは泡なしが基本|
|「価格・ブランド性」|シャンパンは高級感と演出性に富む|
