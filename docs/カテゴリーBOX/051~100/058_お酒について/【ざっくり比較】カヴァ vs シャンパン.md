## 💰価格の違いの理由は？

1. **原産地保護制度（AOC）**  
    　シャンパンは「シャンパーニュ地方での生産」でなければ名乗れない → 独占的価値
    
2. **手間と熟成期間**  
    　シャンパンの方が平均的に**長期熟成**。その分、手間と時間＝コストに。
    
3. **ブランド価値**  
    　モエ・エ・シャンドン、ドン・ペリニヨンなど、ブランド力が価格を押し上げています。
    
4. **需要と供給**  
    　世界中の高級レストランやセレブがシャンパンを選ぶ → 需要により高価格帯が維持

## 🎯 結論

- **普段飲みや手頃なパーティーにはカヴァが最強コスパ**
    
- **特別な日やギフト、ラグジュアリー演出にはシャンパンが適役**
    

どちらも「瓶内二次発酵」の本格派ですが、値段は**ブランドと熟成の重み**で決まっています。
