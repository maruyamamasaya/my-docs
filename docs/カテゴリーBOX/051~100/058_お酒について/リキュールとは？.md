「リキュール」は、世界中で多様に楽しまれているお酒ですが、意外と定義や分類を知らない人も多いかもしれません。  
ここでは、**リキュールの定義・種類・製造方法・代表銘柄・飲み方**まで、総合的にわかりやすく解説します。

---

# 🍸 リキュールとは？

## ✅ 定義：

**蒸留酒に、果実・ハーブ・香辛料・クリーム・ナッツなどを加え、甘味・香味をつけた混成酒**です。  
通常、**糖分が多く、アルコール度数は15〜30%前後**が一般的。

# 🧪 製造方法

1. **浸漬法（マセレーション）**  
    　素材（果実やハーブ）をアルコールに漬け込んで抽出  
    　→ フルーツリキュールに多い
    
2. **蒸留法（ディスティレーション）**  
    　漬け込んだ後、再蒸留して香りを凝縮  
    　→ ハーブ・スパイス系に多い
    
3. **混合法（コンパウンディング）**  
    　香料やエッセンス、糖分などを加えて調整  
    　→ 工業的なリキュールに多い

# 🥂 飲み方・使い方

|スタイル|内容|
|---|---|
|ストレート|デザート後の一杯、チョコやチーズと合わせる|
|ロック|甘さが引き締まり、香りが立ちやすい|
|ソーダ割り|梅酒や果実系リキュールに最適。すっきり飲める|
|ミルク割り|カルーアミルクやベイリーズなど、女性にも人気|
|カクテルベース|マルガリータ（オレンジリキュール）、B-52など多数|
|デザート・製菓用|ケーキ、ティラミス、チョコレートに香りづけとして|

# 🍸 リキュールの魅力

- 種類が非常に多く、**色・香り・甘さで個性豊か**
    
- カクテルベースに必須。**創造的なアレンジが楽しめる**
    
- アルコール初心者や甘党にも人気
    
- デザート・料理・製菓にも応用可能
