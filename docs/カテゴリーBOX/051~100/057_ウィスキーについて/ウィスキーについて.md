## 🔧 製法（基本工程）

ウィスキーの製法はビールに似ていますが、蒸留と熟成を経る点が特徴です。主に以下の工程です：

1. **原料の準備（麦芽化 / 糖化）**
    
    - 大麦を水に浸し、発芽させて麦芽（モルト）にします。
        
    - 発芽を止めるために乾燥（ピートを使えばスモーキーな香りがつく）。
        
2. **糖化**
    
    - 麦芽を砕いて温水と混ぜ、糖分を抽出（麦汁を得る）。
        
3. **発酵**
    
    - 麦汁に酵母を加えて発酵 → アルコール度数約7〜10％の発酵液ができる（「ウォッシュ」と呼ぶ）。
        
4. **蒸留**
    
    - 発酵液を銅製のポットスチルなどで2回以上蒸留し、アルコール度数60〜70％のニューポット（新酒）を得る。
        
5. **熟成**
    
    - オーク樽で最低3年間以上熟成。色や香り、味がまろやかになる（ウィスキーの特徴を決める重要工程）。
        
6. **瓶詰め**
    
    - 熟成後、加水調整し（通常40〜46％に）瓶詰め。

## 🧪 成分

|成分|説明|
|---|---|
|アルコール（エタノール）|主成分。平均40〜50％（樽出しで60％以上のことも）。|
|水|加水によって調整。ミネラル分を含む仕込み水が味に影響。|
|フーゼル油|長鎖アルコールなど、香味成分の一部。蒸留や熟成で生成。|
|フェノール化合物|ピート（泥炭）での乾燥で生成。スモーキーさの原因。|
|エステル類|熟成中に形成される香り成分（バニラ、果実香など）。|
|リグニン分解物|樽の木から溶け出す。色素（カラメル系）や香味を与える。|

## 🧠 効用（あくまで適量の場合）

|効用|説明|
|---|---|
|血行促進|アルコールが血管を拡張 → 体が温まる感じがする。|
|リラックス効果|精神的な緊張緩和。特にナイトキャップ（寝酒）として好まれる。|
|抗酸化作用（仮説）|熟成中に生じるフェノール化合物やエラグ酸に抗酸化作用の報告も。|
|食欲増進|香りやアルコール刺激で食欲がわくことも。|

※ただし、過剰摂取すれば **肝臓障害、依存症、血圧上昇、睡眠障害** などのリスクが高くなります。

## 🍷補足：ウィスキーの種類（ざっくり）

|種類|特徴|
|---|---|
|スコッチ|スコットランド産、ピート香あり（特にアイラ）。|
|バーボン|アメリカ産、トウモロコシ主体、バニラ香が強い。|
|アイリッシュ|アイルランド産、軽く滑らか。3回蒸留が主流。|
|ジャパニーズ|スコッチ由来の製法。繊細な香りとバランス。|
