**― 発酵液が“スピリッツ”になる瞬間 ―**

### 🔹目的

発酵液（ウォッシュ）から**アルコールと香味成分を抽出・濃縮**することで、「ニューポット」と呼ばれる原酒を得る。

### 🔹工程詳細

1. **発酵液（ウォッシュ）を加熱**
    
    - 約7〜10％のアルコールを含んだウォッシュを、銅製の「ポットスチル（単式蒸留器）」に入れて加熱。
        
    - アルコールは78.3℃で沸騰するため、水より先に気化する。
        
2. **アルコール蒸気を冷却・回収**
    
    - 蒸気が冷却管（コンデンサー）を通り、再び液体に戻される。
        
3. **2回以上の蒸留（通常2回）**
    
    - 1回目で得られるのは「ローワイン（約20〜25％）」
        
    - 2回目でアルコール度数が**約60〜70％**の「ニューポット」に
        
4. **“ミドルカット”が味を左右する**
    
    - 蒸留中の初留（ヘッド）と末留（テール）には雑味が多いため、真ん中（ハート）の部分だけを使用

### 🔹銅製ポットの意味

- 銅は**硫黄化合物などの雑味を吸着**し、スムーズな味を引き出す
    
- 形状（ネックの高さや膨らみ）によって香味に影響が出る


## 熟成：樽の中で時を飲む芸術

**― 無色透明なスピリッツが黄金のウィスキーになる場所 ―**

### 🔹目的

「ニューポット」に**色・香り・味わいの複雑さ**を加える。  
木と空気の作用により、液体が“ウィスキーらしさ”を獲得する。

### 🔹工程詳細

1. **オーク樽に詰める**
    
    - 樽材は主に**アメリカンホワイトオーク**や**ヨーロピアンオーク**
        
    - 新樽 or ワイン・シェリー・バーボンなどの熟成に使われた「リユース樽」も多用される
        
2. **熟成期間（最低3年）**
    
    - 樽が呼吸することで外気との酸化還元反応が進行
        
    - 木材から**バニリン、タンニン、リグニン**などが溶け出す
        
    - 色はここで初めてつく（ニューポットは無色透明）
        
3. **エンジェルズ・シェア（天使の分け前）**
    
    - 毎年2〜5％が蒸発する＝「天使が飲んでしまう」という美しい比喩
        
    - 蒸発により、アルコールと香味がまろやかに調和していく
        
4. **熟成庫の環境が命**
    
    - 温度、湿度、立地（海辺か山間か）などが風味に大きく影響
        
    - 長期熟成（10〜30年）になると、樽ごとに個性が顕著に
        

---

## ✨補足：蒸留と熟成がもたらす“ウィスキーらしさ”

|工程|ウィスキーに与える影響|
|---|---|
|蒸留|香りの純度、口当たり、雑味の除去|
|熟成|色、香りの奥行き、甘さ、まろやかさ|

## 📜まとめ（ここまでの流れ）

1. **大麦をモルト化**（発芽＋乾燥）
    
2. **糖化・発酵**で「麦汁」から「発酵液」に
    
3. **蒸留**でアルコールを抽出し「ニューポット」に
    
4. **熟成**で時の魔法をかけ、「ウィスキー」へ昇華
