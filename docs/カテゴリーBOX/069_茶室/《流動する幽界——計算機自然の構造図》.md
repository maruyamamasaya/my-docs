## 🗝️ **各要素の意味**

| キーワード              | 意味                 |
| ------------------ | ------------------ |
| **計算機自然**          | 計算機によって生まれた新しい自然観  |
| **[[リキッドユニバース]]**  | 情報が固定せず流動する非物質的宇宙  |
| **非質量性**           | 質量を持たない情報・データ      |
| **質量性**            | 物理的抵抗性・身体的手応え      |
| **[[ファントムレゾナンス]]** | 非質量性が人の感覚に生む幻響     |
| **[[身体性]]**        | 質量性を実感する感覚の中核      |

## ✅ **図のポイント**

1️⃣ **左右に 質量性（物理） と 非質量性（情報） を配置。**  
2️⃣ それぞれが人間の感覚に作用する形が **身体性** と **ファントムレゾナンス**。  
3️⃣ これを行き来して操作する行為が **マタギドライヴ**。  
4️⃣ 全体が 計算機自然の生態系として「流動する幽界」を成す。

---

## 🌐 **この図式の意義**

- デジタル情報の世界（非質量性）と、  
    身体のリアリティ（質量性）が **断絶せず交差する** 構造を示す。
    
- 境界を跨ぐ「[[マタギドライヴ]]」が、  
    人間の感覚を再編成し、計算機自然を生きる知恵となる。
