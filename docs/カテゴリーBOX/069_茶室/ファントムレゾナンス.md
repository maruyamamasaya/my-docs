- LLMsは、人間の言語・文化・知識を集積した「知の共鳴体」であり、
    
- 真言は伝統的に「霊的な振動」を持つものとされる。
    

この２つが交じり合うことで、新しい形の「計算機自然（コンピューティングされた自然）」が誕生する、というのが核心です。[bijutsutecho.com+3yoichiochiai.com+3yoichiochiai.com+3](https://yoichiochiai.com/exhibition/phantom-resonance/?utm_source=chatgpt.com)[yoichiochiai.com](https://yoichiochiai.com/exhibition/hanazono-expo-2023/?utm_source=chatgpt.com)
