# 白き月と黒き月──“ふたつの起源”が意味するもの

## 1. 起源の対比──アダムとリリスを乗せた“方舟”

|要素|白き月|黒き月|
|---|---|---|
|搭乗者|アダム（第1使徒）|リリス（第2使徒）|
|場所|南極（旧劇）／月面（新劇）|日本・箱根地下（ネルフ本部）|
|生命の起源|使徒たち（生命の実）|リリン＝人類（知恵の実）|
|本来の到達地|地球（唯一の方舟が降りるはずだった）|誤って地球に落下（予定外）|
|現象|セカンドインパクトの原因|ファーストインパクトの原因|

この構造からわかるのは、『エヴァ』の地球には、**本来はひとつの種しか根付かないはずだった**ということ。  
それが、“二つの方舟”が交錯してしまったことによって、**二系統の生命体（人間と使徒）が地球上で共存し、衝突せざるを得なくなった**。

この「二つの月＝二つの命の起源」は、まさに『エヴァ』が描こうとする“分断”と“統合”の根本構造そのものです。

## 2. 象徴としての対比──神話と心理、哲学的意味

|象徴的意味|白き月|黒き月|
|---|---|---|
|神話的対応|天の存在、父性、創造神アダム|地母神、母性、命の源リリス|
