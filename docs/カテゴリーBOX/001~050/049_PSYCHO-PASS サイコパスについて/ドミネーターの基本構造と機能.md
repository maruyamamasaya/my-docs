ドミネーターは、シビュラシステムと直結し、対象者の「犯罪係数（Crime Coefficient）」に基づいて作動する銃器です。外見は近未来的で、使用者の声に応じて状態が変化する音声認識型。また、使用者ごとに生体認証されており、公安局の監視官および執行官のみが使用可能です。

### 主なモード

1. **パラライザー**（Paralyzer）
    
    - 犯罪係数100以上で使用可能。対象を無力化する麻酔銃モード。
        
2. **エリミネーター**（Eliminator）
    
    - 犯罪係数300以上で発動。対象を内部から破裂させる致死モード。
        
3. **デコンポーザー**（Decomposer）
    
    - 対象が人間以外、あるいは危険度が極めて高い物体である場合に限定される。物質を分子レベルで分解し完全消滅させる。
        

さらに、「ドミネーター自体がシビュラシステムの端末」であるという特性上、銃である以上に、**判断機能を備えた人工知能的な存在**でもあります。

## 🧠 哲学的・倫理的な考察

### ① 正義の外注化と責任の所在

ドミネーターの存在は、「人間が他人を裁く」行為から「システムが人間を裁く」構造へのシフトを象徴しています。使用者（監視官・執行官）はあくまで「執行の媒介者」であり、判断そのものはシビュラシステムによって行われます。つまり、正義の判断を個人が放棄し、機械に委ねているわけです。

→ **問い**：「システムに命じられた殺人は、果たして正義か？」

### ② 意識と罪の分離

シビュラが測るのは「意識（精神）」であり、「行動」ではありません。これは「罪を犯したかどうか」ではなく、「罪を犯しうる精神状態かどうか」で裁くという思想です。ドミネーターはその思想を物理的に実行する装置であり、**未来の可能性に対して死刑を下す銃**とも言えるのです。

→ **問い**：「人は“犯罪を犯す可能性”だけで裁かれて良いのか？」

### ③ 武器の人格性

ドミネーターには女性の声が設定されており、シーンによっては人間のような意志を持つかのように振る舞います。この「銃に人格がある」という演出は、攻撃と判断、倫理と暴力の融合を象徴し、**銃＝裁判官＝処刑人**という多重の役割を視覚化しています。

## 🌐 現実世界との関係性

現実の監視技術（AI監視カメラ、予測アルゴリズムなど）や、自律型兵器（ロボット兵器・ドローン）とドミネーターには多くの共通点があります。未来の技術としての可能性、またその危険性を視覚的に、そして物語的に描き切った点で、ドミネーターはフィクションの枠を超えて現実への強烈な警告でもあります。
