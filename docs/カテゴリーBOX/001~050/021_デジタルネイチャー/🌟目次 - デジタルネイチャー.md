[[デジタルネイチャーとは？]]
→テクノロジーが進化した結果、デジタルと自然の境界が消え、人間の認識や社会の在り方そのものが大きく変わる未来像を指しています。
これは、ポストモダンやシンギュラリティを超えて、人間とテクノロジーが溶け合い、新たな「自然」として共存する世界観。つまり、かつて「機械」と「自然」が別物だった時代は終わり、これからは計算機（コンピューター）そのものが自然の一部になる。

[[サイバネティクスとは？]]
人間・動物・機械の制御と通信の仕組みを統一的に説明する学問

[[ユビキタスとは？]]
ラテン語が語源で「どこにでも存在する」という意味があります。テクノロジーの文脈で言う「ユビキタス」は、「コンピューターやネットワークが生活のあらゆる場所に溶け込み、意識しなくても情報やサービスにアクセスできる状態」を指します。
