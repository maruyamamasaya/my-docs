- **カール・マルクス（Karl Marx）**
    - ドイツの哲学者・経済学者
    - 社会の経済的構造に焦点を当て、「階級闘争」や「資本主義の批判」を展開

- **マックス・ウェーバー（Max Weber）**
    - ドイツの社会学者・経済学者
    - 社会の価値観・文化・宗教に注目し、「権威」「合理化」「官僚制」などの概念を発展

---

## 2. **違い**

| 観点       | マルクス                                    | ウェーバー                          |
| -------- | --------------------------------------- | ------------------------------ |
| 社会の捉え方   | 経済構造（生産手段の所有）を社会の基盤とし、階級による対立で歴史が進むと考える | 経済だけでなく、宗教や文化・価値観など多元的に社会を理解する |
| 主な分析対象   | 階級闘争（資本家と労働者の対立）                        | 権力・支配の正当性、官僚制、宗教の役割など          |
| 理論の焦点    | 経済的土台（下部構造）が社会全体を決定する「唯物史観」             | 社会の合理化プロセスとそれがもたらす影響を分析        |
| 解決策・理想社会 | 階級闘争の結果としての共産主義社会                       | 理想社会を提示するよりも、現実を冷静に分析          |

---

## 3. **類似点**

- 社会の構造と変化を分析し、「なぜ今の社会はこうなっているのか」を説明しようとした
- 資本主義社会の矛盾や問題点に注目した
- 社会変動や権力の構造に対する鋭い批判精神を持つ

---

## 4. **代表的な理論・概念**

### マルクス

- **唯物史観**  
    「経済の仕組み（生産手段）が社会構造と人間の意識を決める」
- **階級闘争**  
    社会は常に「支配する側（資本家）」と「支配される側（労働者）」の対立によって変化する
- **搾取と疎外**  
    労働者は自分が作った価値の大部分を資本家に奪われている（搾取）、その結果、自分の労働や社会から疎外される

### ウェーバー

- **プロテスタンティズムの倫理と資本主義の精神**  
    「禁欲的で勤勉なプロテスタント（カルヴァン派）の倫理観が、資本主義の発展を促した」
- **合理化**  
    社会は伝統や感情から離れ、「効率的で合理的な手段」を追求する方向に進む
- **支配の3類型**
    - カリスマ的支配（リーダー個人の魅力による支配）
    - 伝統的支配（王族や貴族など慣習による支配）
    - 合法的支配（法に基づく近代官僚制）

---

## 5. **わかりやすい概念の例え**

- **マルクス**  
    →「ピラミッド構造」  
    経済的に持っている人（資本家）が上にいて、多くの人（労働者）が下で働かされている  
    その構造を壊して「みんなで平等に働き、平等に分け合おう」というのが理想
    
- **ウェーバー**  
    →「オフィスとルール社会」  
    「みんながルールに従って働く仕組みが進んでいるよね。でも、それって人間的にどうなんだろう？」  
    官僚制は便利だけど、冷たいシステムになりすぎる危険性もある、と考えた
