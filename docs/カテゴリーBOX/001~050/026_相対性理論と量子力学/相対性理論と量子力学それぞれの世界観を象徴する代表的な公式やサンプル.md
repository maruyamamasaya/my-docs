# 🧠 相対性理論（アインシュタイン）

## 🔷 特殊相対性理論（1905）

### 📌 代表公式①：質量とエネルギーの等価性

$E = mc^2$

- **E**：エネルギー
    
- **m**：質量
    
- **c**：光の速さ（約3.0×10⁸ m/s）
    

🔹 意味：**質量はエネルギーそのもの**であり、わずかな質量でも莫大なエネルギーを持つ  
→ 核分裂・核融合のエネルギー源

---

### 📌 代表公式②：時間の遅れ（時間の伸び）

$t' = \frac{t}{\sqrt{1 - \frac{v^2}{c^2}}}$

- **t**：静止系での時間
    
- **t'**：高速移動している物体の中での時間
    
- **v**：相対速度
    
- **c**：光速
    

🔹 意味：**物体が高速で移動すると、時間がゆっくり進む**（GPSの補正にも使われている）

---

## 🔷 一般相対性理論（1915）

### 📌 代表公式③：アインシュタイン方程式（宇宙の形を決める方程式）

$R_{\mu\nu} - \frac{1}{2}g_{\mu\nu} R + \Lambda g_{\mu\nu} = \frac{8\pi G}{c^4} T_{\mu\nu}$

- **左辺**：時空の曲がり（リッチテンソル、スカラー曲率、計量テンソルなど）
    
- **右辺**：物質やエネルギーの分布（ストレスエネルギーテンソル）
    

🔹 意味：**「物質があれば、空間は曲がる」→「曲がった空間が、物体の運動を決める」**

# 🔬 量子力学（シュレーディンガー、ハイゼンベルク、ボーア ほか）

## 📌 代表公式①：シュレーディンガー方程式

$i\hbar \frac{\partial}{\partial t} \Psi(x, t) = \hat{H} \Psi(x, t)$

- $Psi(x, t)$：波動関数（粒子の状態を表す）
    
- **$hat{H}$**：ハミルトニアン（エネルギー演算子）
    
- **$hbar$**：プランク定数（量子スケールの単位）
    

🔹 意味：**粒子の動きは“波”のように広がる可能性で記述される**

---

## 📌 代表公式②：不確定性原理（ハイゼンベルク）

$\Delta x \cdot \Delta p \geq \frac{\hbar}{2}$

- **$\Delta x$**：位置の不確かさ
    
- **$\Delta p$**：運動量の不確かさ
    

🔹 意味：**粒子の位置と運動量を同時に正確には知ることができない**

---

## 📌 代表公式③：波動関数の確率解釈

$|\Psi(x)|^2 = \text{その場所に粒子が存在する確率密度}$

- 観測するまでは、「粒子はあちこちに存在している可能性」を持つ
    
- 観測した瞬間に「1つの状態に収束」する（波動関数のコラプス）

# 🧭 相対性理論 vs 量子力学：数式的な違い・性格

|比較項目|相対性理論|量子力学|
|---|---|---|
|数学の中心|幾何学・テンソル・微分方程式|波動関数・線形代数・確率|
|対象|宇宙・重力・時空|原子・電子・素粒子|
|世界観|決定論・連続的|不確定性・確率的|
|キーワード|曲がる時空、光速不変|波動性、量子跳躍、もつれ|

---

これらの数式と概念の違いこそが、**両者の“矛盾”や“統一の難しさ”の原因**でもあるんです。
