### 1. 音楽の主な役割

- 神への祈り・宗教儀式が中心
- 教会音楽（グレゴリオ聖歌・ネウマ譜）による単旋律（モノフォニー）が基本
- 言葉（聖書・祈り）を音で支えるもの
### 2. 音楽の特徴

- ハーモニーは未発達（和音がほぼない）
- モード（教会旋法）による神秘的な響き
- リズムは曖昧（言葉の自然な流れに合わせる）
- 楽譜はネウマ譜 → 五線譜の始まり
### 3. 音楽の担い手

- 教会・修道院
- 宮廷の吟遊詩人・トルバドゥールも存在
### 世界観
- 人間よりも「神」が中心
- 音楽は精神性・祈りの道具
- 芸術は匿名性（作者名は重要でない）

## ルネサンス以降（音楽の大転換）

### ルネサンスとは？

15世紀〜16世紀頃、イタリアを中心に起きた「人間回帰・古代文化復興」の時代。

「ルネサンス＝再生・復興」という意味。  
芸術・音楽・科学・建築・哲学が大きく変わっていきます。

---

### 1. 音楽の主な役割

- 神への祈り＋人間の感情や美的表現
- 宗教音楽に加えて、世俗音楽（恋愛・自然・日常）の発展

### 2. 音楽の特徴

- ポリフォニー（多声音楽）の発展  
    → 複数の旋律が独立しながら美しく絡む技法
- 和声（ハーモニー）の誕生
- リズムや拍子が明確になる
- 楽器音楽が独立して発展
- 調性（長調・短調）の発明につながる土台ができる

---

### 3. 音楽の担い手

- 教会音楽だけでなく、王侯貴族・市民・音楽家個人へと拡大
- 作曲家の名前が重要視されるようになる（芸術家の自立）    

---

### 世界観の変化

| 中世        | ルネサンス以降   |
| --------- | --------- |
| 神中心・祈りの文化 | 人間中心・個人表現 |
| 芸術は宗教的道具  | 芸術は人間の創造性 |
| 無名性が美徳    | 作者性・個性の追求 |

## 音楽史的な大きな流れ

| 時代             | 音楽の特徴        | キーワード           |
| -------------- | ------------ | --------------- |
| 中世（〜15世紀）      | モノフォニー（単旋律）  | 神への祈り・教会・聖歌・モード |
| ルネサンス（15〜16世紀） | ポリフォニー（多声音楽） | 人間回帰・和声・世俗音楽    |
| バロック（17世紀〜）    | 和声・旋律美・オペラ誕生 | ドラマ・感情表現・楽器の発展  |
| 古典派（18世紀〜）     | 調性音楽・均整美     | ソナタ形式・交響曲       |
| ロマン派（19世紀〜）    | 個性・感情の爆発     | 自由・個人・民族主義      |

---

## まとめ｜ルネサンス以前と以降の違いとは？

| 比較軸   | ルネサンス以前（中世） | ルネサンス以降（近世〜） |
| ----- | ----------- | ------------ |
| 音楽の中心 | 教会・神への祈り    | 人間・個人の感情表現   |
| 音楽技法  | 単旋律（モノフォニー） | 多声・和声・調性の発展  |
| 世界観   | 神中心・宗教性重視   | 人間中心・創造性重視   |
| 音楽文化  | 教会・修道院文化    | 市民・芸術家文化へ    |
