#### 概要
哲学とは、人間・世界・知識・真理・価値・存在など、根本的な問いについて考える学問。ギリシャ語の「フィロソフィア（philosophia）」＝「知を愛する」から来ており、古代ギリシャの哲学者ソクラテスやプラトンなどに起源を持つ。
#### 目的
哲学は「なぜ？」を問い続けることが中心。科学や宗教とは違い、明確な正解があるとは限らず、思考そのものに価値があるとされる。

例
- 「私はなぜ生きるのか？」
- 「正義とは何か？」
- 「世界は本当に存在しているのか？」
#### 主な分野
哲学は多くの分野に分かれている。それぞれ独自のテーマを持ちつつ、互いに関連し合っている。

| 分野                 | 内容                        |
| ------------------ | ------------------------- |
| **形而上学（けいじじょうがく）** | 世界の本質、存在とは何かを問う           |
| **認識論（にんしきろん）**    | 知識や真理について考える。「人は何をどう知るのか」 |
| **倫理学（りんりがく）**     | 善悪、正義、生き方について考える          |
| **論理学**            | 論理的な思考や推論のルールを研究          |
| **美学**             | 美とは何か、芸術の意味を探る            |
| **政治哲学**           | 国家、権力、自由、正義など社会のあり方を考える   |

### 有名な哲学者（ざっくり紹介）

- **ソクラテス**（古代ギリシャ）：「無知の知」で有名。対話を通じて真理を探る。    
- **プラトン**：理想の世界「イデア」を提唱。
- **アリストテレス**：あらゆる学問の土台を築いた論理の巨人。
- **デカルト**：「我思う、ゆえに我あり」——近代哲学の父。
- **カント**：道徳や認識の哲学を深めたドイツの哲人。
- **ニーチェ**：「神は死んだ」など過激だが鋭い批評家。
- **ハイデガー、サルトル**：20世紀の実存主義者たち。生きる意味を問う。
