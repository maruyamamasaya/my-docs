日本の古典文学には、詩歌、物語、随筆、軍記など、さまざまなジャンルがあります。以下に代表的な作品をジャンル別に紹介します。

## 🏯 日本の有名な古典文学一覧（ジャンル別）

### 📖【物語・小説】

| 作品名          | 概要・特徴                   | 作者        | 時代   |
| ------------ | ----------------------- | --------- | ---- |
| **[[竹取物語]]** | かぐや姫の物語。日本最古の物語文学。      | 不詳        | 平安前期 |
| **[[伊勢物語]]** | 和歌と短編物語の組み合わせ。恋と放浪の人生。  | 在原業平（説あり） | 平安前期 |
| **[[源氏物語]]** | 光源氏の恋愛と人間ドラマ。世界最古の長編小説。 | 紫式部       | 平安中期 |
| **[[平家物語]]** | 平家の興亡と無常観を描いた軍記物語。      | 琵琶法師ら     | 鎌倉時代 |
| **[[太平記]]**  | 南北朝の戦乱を描く軍記物語。          | 不詳        | 室町時代 |

## 💡古典を読む意義

- 日本語の美しさを体感できる
    
- 日本人の価値観（無常観、自然観、美意識）に触れられる
    
- 現代文化（漫画・アニメ・小説）にも多く影響を与えている
